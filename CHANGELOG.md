# Changelog

All notable changes to HexBrief. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [SemVer](https://semver.org/).

## [1.0.0] - 2026-11-15

First complete release: feeds in, a validated daily brief out, published over STIX/TAXII and to a TLP:CLEAR archive.

### Added
- **Phase 0, repo and lab sizing** (#1): repo skeleton, `CLAUDE.md`, ADR-001 (hardware path), `.wslconfig` sizing, `gen-secrets.ps1` / `check-env.ps1`, pre-commit with gitleaks.
- **Phase 1, stixkit** (#3): TAXII 2.1 client (pagination, `added_after`, retries, typed errors), STIX 2.1 bundle build and validate, TLP 2.0 markings, medallion TAXII server on 127.0.0.1:5000 (ADR-002).
- **Phase 2, MISP** (#4): MISP 2.5 on demand on 127.0.0.1:8443 with a lab CA. Default feeds and warninglists are enabled, a read-only collector exports MISP events as STIX 2.1, and `fresh_only` handles the `publish_timestamp` pitfall (ADR-003).
- **Phase 3, OpenCTI** (#5): OpenCTI 7 on 127.0.0.1:8088 with MITRE ATT&CK, CISA KEV, AlienVault OTX and TAXII2 connectors. Also an abuse.ch API importer with a confidence-capped user, a `daily-briefs` TAXII collection and a read-only token (ADR-004).
- **Phase 4, local LLM** (#6): Ollama with JSON-schema output, a benchmark of three models, and `qwen3.5:4b` primary with `llama3.2` fallback (ADR-005). The faithfulness validator checks IPs, domains, URLs, hashes, CVEs and ATT&CK IDs, including defanged forms.
- **Phase 5, brief engine** (#7): normalize, two-pass dedupe, rule-based scoring with written reasons, a completeness check, retries with feedback and a facts-only fallback. Outputs are Markdown, HTML, JSON and a STIX 2.1 Report.
- **Phase 6, publish** (#8): PDF via headless Edge, a push to OpenCTI and medallion, a GitHub Pages archive that refuses anything that isn't TLP:CLEAR, and an optional webhook.
- **Phase 7, automation** (#9): `scripts/daily.ps1` for 07:00 MYT orchestration, `install-schedule.ps1`, `hexbrief doctor`, weekly backup, CI (tests, ruff, gitleaks, bandit, pip-audit, SHA-pinned actions) and Dependabot (ADR-006).
- **Phase 8, quality and demo** (#12): `hexbrief demo` builds a full brief from recorded TLP:CLEAR data with no keys or services and passes the same validation gate. The HTML brief is redesigned around the TLP strip, the README is demo-first, and the architecture diagram and sample brief are new.
- **Phase 9, launch:** this changelog, the write-up, launch material and interview prep.

### Fixed
- Unmarked data now fails closed to TLP:AMBER, and an indicator's stricter TLP raises its finding's TLP.
- IPs inside URL paths are now defanged in human-readable outputs.
- The narrative step no longer falls back to facts-only when retries overflow the model context. The best faithful answer is kept.
- `hexbrief doctor` treats an unclosed quote in `.env` as malformed (#2).

### Security
- Every service binds to 127.0.0.1, secrets are generated by script and kept in git-ignored env files, and only TLP:CLEAR is published.
- Four transitive CVEs pinned by pycti are ignored in pip-audit, each with a written reason and a removal trigger (ADR-006).
